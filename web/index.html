Spacecraft interface

Every lamp is a bit the flight software drives on an output channel. Switches set input discretes the software reads.

Try it

Press RSET first to clear the RESTART lamp lit at power-on. Then key a verb and noun and press ENTR.

V35ELamp test: every lamp and segment on for five seconds (AGC warning then fades over about 20 seconds)
V16N36EMonitor the mission clock (hours, minutes, seconds·100)
V37E00EChange major mode to P00, the idle program
V05N09EShow the alarm codes
V25N36ELoad a new clock time, one register at a time
V91EShow the rope's bank checksums (press PRO to step)

Tap a recipe to key it in. On a keyboard: digits, V verb, N noun, Enter ENTR, C CLR, R RSET, K KEY REL, P PRO, + −.

What's running

The software was assembled at build time from the AGC source in chrislgarry/Apollo-11 with the yaYUL assembler, then checked word for word against the Virtual AGC project's verified rope. The CPU is the Virtual AGC engine (yaAGC) compiled to WebAssembly, clocked at the real 85,333 memory cycles per second.

Nothing here is scripted: every digit and lamp is set by the 1969 code writing to the computer's output channels.
